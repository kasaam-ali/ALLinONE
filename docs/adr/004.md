# ADR-004: JWT roles + DB role source of truth

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: ALLinONE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
Roles: `admin` | `operator` | `viewer`. JWT carries role; refresh reloads from DB. Deny-by-default on API.

| Cap | viewer | operator | admin |
|-----|:------:|:--------:|:-----:|
| Read domain | ✓ | ✓ | ✓ |
| Audit read | | ✓ | ✓ |
| Task start/cancel, approve, publish, memory write | | ✓ | ✓ |
| Users + disable agents + global memory write | | | ✓ |
