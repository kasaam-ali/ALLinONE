# ADR-002: Postgres SoT; Redis locks only

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: ALLinONE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
Run, Approval, StageEvent, AuditLog live in Postgres. Redis holds run locks, session/jti blacklist, optional queue/pubsub - never sole approval or stage truth.

## Consequences
Workers must commit stage+approval transitions in DB before releasing locks. No Redis-only gate flags.
