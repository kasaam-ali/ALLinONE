# ADR-005: Shared types via OpenAPI → TS

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: ALLinONE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
`packages/shared` holds TaskStatus, Stage, Role, Gate, ApprovalDecision and DTOs. Prefer OpenAPI export from FastAPI → TS; hand-sync only if generator late.

## Consequences
Backend owns schema; Frontend consumes shared - reduces morning drift.
