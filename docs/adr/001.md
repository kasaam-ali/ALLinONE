# ADR-001: Mock LLM behind GODMODE_MOCK_LLM

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: GODMODE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
All model calls go through a provider facade. When `GODMODE_MOCK_LLM=1`, return deterministic plan/research/execute/verify/report artifacts. Compose/CI run with zero API keys.

## Consequences
Agentic ships mock path first. Real provider is post-MVP. Approval gates still apply in mock mode.
