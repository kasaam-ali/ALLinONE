# ADR-003: Two hard approval gates

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: ALLinONE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
Gates: `after_plan` (before research) and `before_publish` (after verify → publish Report). `before_execute` **cut**.

Flow: `queued → running(plan) → awaiting_approval → running(research→execute→verify) → awaiting_approval → succeeded`.

Invariants: no advance without Approval approved; decide idempotent (409); StageEvent+AuditLog every transition; cancel rejects open approvals.
