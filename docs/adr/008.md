# ADR-008: Browser tools only with existing credentials

- Status: **Accepted** (CTO lock 2026-11-03)
- Owner: GODMODE Architect
- Date: 2026-11-03 Asia/Karachi

## Decision
Integrations may call browser/API tools only where credentials/permissions already exist. Architect does not block MVP on live browser automation.

## Consequences
Mock/graph path must succeed without browser. Live tools are additive.
