# App Router routes

- `layout.tsx` root layout, `Shell.tsx` nav and session guard (GET /auth/me).
- `login/` sign in.
- `page.tsx` Dashboard.
- `tasks/` task list and `tasks/[id]` task detail (Run, StageEvent, Artifact, Approval).
- `workforce/` agents list.
- `activity/` audit log.
- `reports/` reports list.
